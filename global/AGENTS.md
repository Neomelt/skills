# 全局协作约定

- **个人看板跟踪（`todo-board`）**：收到多步骤、需修改项目文件或耗时较长的任务时，**在修改文件前先加载 `todo-board` 技能**，用独立的 `todo list` → `todo agent` / `todo add` 将事项挂上看板（标题与备注尽量精简，一句话让人看懂想起来即可；做完用 `todo set` 更新进展，保持 `agent` 状态等用户确认，不要自行标完成；若本机无 `todo` 命令或看板连不上则直接跳过）。纯问答不挂；一两步极小改动若遇看板守门拦截，先单独执行 `kanban-skip "<简短原因>"` 放行。
- **个人经验沉淀（`distill-skill`）**：当用户要求把当前任务的做法、排障结论或方法论提炼为 Skill 时，加载 `distill-skill` 技能归档至 `~/skills` 并执行跨端同步。
